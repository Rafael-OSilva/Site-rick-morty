# 🚀 Rick and Morty - Personagens

Projeto desenvolvido para a disciplina de Desenvolvimento Web, demonstrando o consumo de API pública e manipulação dinâmica do DOM.

## 📋 Funcionalidades

- ✅ Consumo da API Rick and Morty utilizando Fetch API
- ✅ Cards gerados dinamicamente via JavaScript
- ✅ Filtros por status (Vivos, Mortos, Desconhecido)
- ✅ Design responsivo para diferentes dispositivos
- ✅ Loading enquanto aguarda a resposta da API
- ✅ Animações e hover effects nos cards

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura da página
- **CSS3** - Estilização, animações e responsividade
- **JavaScript (ES6+)** - Consumo da API, manipulação do DOM e lógica de filtros
